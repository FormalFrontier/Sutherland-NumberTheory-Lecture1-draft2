**Definition 1.2.** An *absolute value* on a field $k$ is a map $|\,|: k \to \mathbb{R}_{\geq 0}$ such that for all $x, y \in k$ the following hold:

1. $|x| = 0$ if and only if $x = 0$;
2. $|xy| = |x||y|$;
3. $|x + y| \leq |x| + |y|$.

If the stronger condition

4. $|x + y| \leq \max(|x|, |y|)$

also holds, then the absolute value is *nonarchimedean*; otherwise it is *archimedean*.
